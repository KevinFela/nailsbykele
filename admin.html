First-time setup

Connect your studio.

This CMS needs your Supabase project before it can save changes.

  1. Run supabase/setup.sql from your ZIP in Supabase’s SQL Editor.
  2. Create an admin user in Authentication → Users.
  3. Run the admin access command at the end of setup.sql with that user’s ID.
  4. Add your project URL and public publishable key to config.js, then upload the website files.

Replace config.js in your website folder with the downloaded file. Use only the public publishable key, never a secret or service_role key.
